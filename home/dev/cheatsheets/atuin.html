Mental model

Atuin replaces your shell's plaintext history file with a SQLite database that also records each command's exit code, duration, cwd, session, and host. Every history lookup becomes a query you can filter (by scope) and search (by matching algorithm) — two independent axes. It fully owns history navigation in your zsh: both the ↑ arrow and Ctrl+R open its TUI, each tuned differently (see below).

Filter × Search are orthogonal

Filter mode = which commands are candidates (this dir? this session? everywhere?). Search mode = how your query matches them (prefix? fuzzy?). You change filter with Ctrl+R inside the UI; search mode is set in config per entry point.

Two ways in — and they behave differently by design

Entry pointBehaviour (your config)
↑ (up-arrow) Compact 15-line popup, prefix search, global filter — mimics zsh's old up-line-or-beginning-search: type the start of a command, press ↑ to walk matches.
Ctrl+R Full interactive UI, daemon-fuzzy search, global filter — the "explore all my history" entry point. Fuzzy matches anywhere in the command.

Both are wired in ~/.zshrc via eval "$(atuin init zsh)". The up-arrow tuning lives in the *_shell_up_key_binding keys of your config; Ctrl+R uses the base search_mode/filter_mode.

Filter modes Ctrl-R cycles

Which commands are candidates.

globalEverything, everywhere (your default)
hostOnly this machine
sessionOnly this shell session
session-preloadSession, pre-warmed with prior history
directoryOnly commands run in this exact cwd
workspaceAnywhere inside the current git repo tree

Search modes set in config

How your query matches.

prefixMatch from the start (your ↑ mode)
fulltextSubstring match anywhere
fuzzyFuzzy match (skim-style)
daemon-fuzzyFuzzy, executed by the background daemon (your Ctrl+R mode)

Override per-search: atuin search --search-mode fuzzy foo.

Your tuned config the non-defaults

SettingEffect
enter_accept = trueEnter runs, Tab edits
search_mode = "daemon-fuzzy"Fuzzy via daemon for Ctrl+R
search_mode_shell_up_key_binding = "prefix"Prefix search for ↑
filter_mode_shell_up_key_binding = "global"Global scope for ↑

[daemon] enabled/autostart = trueBackground daemon auto-starts; batches writes & sync

Left at defaults but worth knowing: secrets_filter = true (auto-skips AWS/GitHub/Slack/Stripe tokens), store_failed = true (keeps non-zero-exit commands), style = "compact".

CLI cheatsheet

atuin search <query>            # non-interactive search (print matches)
atuin search -i <query>         # open the interactive UI
atuin search --cwd . -e 0 foo  # filter by directory + exit code
atuin history list             # dump history
atuin history last             # the previous command
atuin import auto              # one-shot import from your old histfile
atuin doctor                   # diagnose common issues
atuin info                     # data-dir / env-var locations
atuin default-config           # print the fully-commented default config.toml
atuin gen-completions -s zsh   # shell completions
atuin ai "<question>"           # AI assistant over your history ([ai] enabled)
atuin kv set / get             # small key-value store synced across machines
atuin wrapped                  # year-in-review of your shell usage

Stats

atuin statsAll-time top commands
atuin stats dayToday (also yesterday, dates, ranges)
atuin stats week / monthWindowed totals

Tune grouping with [stats] common_subcommands (e.g. count git push vs just git) and common_prefix / ignored_commands.

Sync & account

atuin registerCreate a sync account
atuin loginLog in on a new machine
atuin syncSync now (-f forces full)
atuin statusShow sync state
atuin keyPrint encryption key to move to another machine
atuin logoutLog out

History is end-to-end encrypted; the server never sees plaintext. auto_sync is on by default, driven by the daemon.

Daemon enabled in your config

With [daemon] enabled = true + autostart = true, a background process owns writes and periodic sync — so daemon-fuzzy searches stay fast and the shell hook does less work. It listens on a unix socket in your atuin data dir. 

atuin daemon                    # run/manage the daemon (experimental)
atuin doctor                    # confirms the daemon is reachable

★ Getting the most out of it

  • Two entry points, two jobs: reach for ↑ when you half-remember the start of a command (prefix, compact); reach for Ctrl+R when you're spelunking (fuzzy, full UI).
  • Filter is a live dial: mash Ctrl+R inside the UI to narrow from global to directory/workspace — hugely underused. "What did I run in this repo?" is one keypress away.
  • Exit codes are queryable: atuin search -e 0 (succeeded) or --exclude-exit 0 (only failures) turns history into a debugging log.
  • It's a database, so back it up by syncing: atuin key + atuin login restores full encrypted history on a fresh machine — your muscle memory follows you.
