Neovim Quick Reference

Stock nvim — no user config · vim/vi are aliased here to nvim

This documents nvim on factory defaults

There is no ~/.config/nvim/, so everything below is what ships built-in — no plugins, no remaps of your own. Neovim's defaults are already more modern than classic vim (mouse on, live substitute preview, sensible search). To make it yours: :Tutor for a hands-on primer, :checkhealth to audit the install, and :help nvim-defaults for the exact option/mapping list. Add a config at ~/.config/nvim/init.lua when ready.

Search & replace

/pat / ?patSearch forward / back (incremental — incsearch on)
n / NNext / previous match
* / #Search word under cursor fwd / back
Ctrl+lClear search highlight (hlsearch is on by default)
:s/old/new/Replace first on line (g = all, gc = confirm)
:%s/old/new/gReplace across the whole file
&Repeat last :s with its flags

inccommand=nosplit is on by default, so :s shows a live preview of every match as you type the command.

Neovim built-in defaults what you get free vs vim

These are on out of the box — no config needed. Verified against this install (:help nvim-defaults).

DefaultEffect
mouse=nviMouse works in normal/visual/insert — click, select, scroll, resize splits
inccommand=nosplitLive preview of :s substitutions as you type
Y = y$Yank to end of line (consistent with C/D)
gc / gccBuilt-in commenting (operator + line), comment-string per filetype
hlsearch + incsearchHighlight matches + jump while typing (Ctrl+l clears)
syntax + filetype onHighlighting and per-filetype indent/plugins enabled automatically
:terminalFull terminal emulator in a buffer
:checkhealth · :InspectDiagnose the install · show highlight/extmark under cursor

Not on by default (unlike some distros): number (line numbers), ignorecase/smartcase, termguicolors (true-color — ghostty supports it, so :set termguicolors is worth it), and system-clipboard integration (see below).

Clipboard not wired by default

Stock clipboard is empty, so plain y/p use nvim's internal registers, not the macOS clipboard. Two ways across the boundary:

"+y / "+pYank / paste via the system clipboard register explicitly
"*ySame, primary/selection register
:set clipboard=unnamedplusMake every y/p use the system clipboard (add to a config to persist)

nvim auto-detects a provider (pbcopy/pbpaste on macOS) — confirm with :checkhealth provider.

★ Working with stock nvim

  • The grammar is the point: operator + motion/text-object composes — learn d/c/y and iw/i"/ip once and every combination just works. That's 80% of the power, zero config.
  • Two quick wins worth typing every session (or putting in a future config): :set number and :set termguicolors — ghostty renders true color, so the second noticeably improves highlighting.
  • Clipboard is the one rough edge: until you set clipboard=unnamedplus, reach for "+y/"+p to cross into macOS.
  • autolock covers you in zellij: nvim is a trigger, so zellij auto-locks and hjkl reaches the editor — see the zellij sheet.
