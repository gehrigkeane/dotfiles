Mental model (vs tmux)

Tmux has one prefix (Ctrl+b) then a letter. Zellij has modes: you press a mode-switch combo, drop into that mode, run single-letter commands, then Enter/Esc returns you to normal. There's also a Tmux mode that mimics tmux prefix-style keys. 

Normal ──Ctrl-p──▶ Pane     ──Ctrl-n──▶ Resize
       ──Ctrl-t──▶ Tab      ──Ctrl-h──▶ Move
       ──Ctrl-s──▶ Scroll   ──Ctrl-o──▶ Session
       ──Ctrl-b──▶ Tmux     ──Ctrl-g──▶ Locked (toggle)

Ctrl+g toggles Locked (passes all keys through to the running app — the autolock plugin does this automatically for nvim/fzf/lazygit/etc).

Reordering tabs Alt-i / Alt-o

Tabs are positional, not identifiers — moving a tab renumbers it. There's no "jump tab to position N"; movement is one slot at a time. No mouse drag support — zellij:tab-bar doesn't implement it. Keyboard or CLI only.

Alt+iShuffle focused tab one slot left (global, any non-locked mode)
Alt+oShuffle focused tab one slot right
zellij action move-tab "Left"Same shuffle, from the shell — useful in scripts
zellij action move-tab "Right"

Walk a tab from position N to 1: focus it (Ctrl+t N), then mash Alt+i until it lands. {index}:{name} in the status bar updates live.

Plugins in your setup

zellij:tab-bar active · top row

Native plugin. Renders the tab strip at the top of every tab. Click a tab to focus, scroll to cycle. No drag-to-reorder — use Alt+i/Alt+o. In default.kdl it's configured with hide_swap_layout_indication "true" to drop the right-side swap-layout label.

zellij:status-bar active · bottom 2 rows

Native plugin, mounted in every layout (default and dev). Top row: session name + mode pill (NORMAL, LOCKED, etc.). Bottom row: context-sensitive keybinding hints for the current mode. Theme-driven by theme "everforest-dark" in config.kdl — no per-layout config.

autolock auto-loads

Watches the focused pane's process and auto-flips zellij into Locked when you open: nvim, vim, fzf, zoxide, atuin, broot, lazygit, lazydocker, btop, htop. Exits Locked when those quit. So hjkl reaches your editor instead of moving panes — no manual Ctrl+g.

room Alt-s · floating

Quick session/pane jumper. Type to filter; Enter to switch. Think tmux choose-tree.

Bars are 100% native now

The community zjstatus plugin was removed — every layout uses the native zellij:tab-bar + zellij:status-bar for theme integration and zero per-layout config. This means zellij attach <name> (which uses the default layout) and zellij --layout dev now render identical bars. Re-add zjstatus only if you ever need shell-command widgets (kubectl context, etc.) that the native bars don't expose.

Things tmux doesn't have, worth learning early

  • Stacked panes — Ctrl+p s. Multiple panes stack like a tabbed group within a pane.
  • Floating panes — Ctrl+p w toggles; Ctrl+p e converts embed↔float; Ctrl+p i pins on top across tabs. Great for a scratch shell.
  • Edit scrollback in $EDITOR — Ctrl+s e. Opens entire scrollback in nvim. Search/yank with full editor power.
  • Pane groups — Alt+p adds focused pane to group; group commands operate on all marked panes.
  • Swap layouts — Alt+[ / Alt+] cycle predefined arrangements without losing pane content.
  • Session resurrection — your config has session_serialization true + serialize_pane_viewport true, so zellij attach --create <name> brings back tabs, cwds, and scrollback after reboot.

CLI cheatsheet (outside zellij)

zellij                          # attach to last or create default
zellij -s work                  # named session
zellij ls                       # list sessions
zellij attach work              # attach by name (uses the default layout → native bars)
zellij kill-session work
zellij --layout dev             # start with ~/.config/zellij/layouts/dev.kdl
zellij action <cmd>             # run any keybind action from shell
zellij run -- htop              # spawn pane running command
zellij edit ~/notes.md          # open file in pane via $EDITOR

★ Mental-model insight

  • Modes vs prefix: tmux's Ctrl+b <key> is one keystroke per command; zellij's mode is sticky — useful when doing many resize/scroll ops in a row, awkward for single quick actions. That's why the Alt global bindings exist: the most common ops bypass modes entirely.
  • Locked mode is the killer abstraction: tmux's biggest wart is keystroke conflict with terminal apps. autolock + Locked mode means your editor never fights for hjkl again — the single biggest QoL win over tmux.
  • Scrollback as a buffer is editor-grade: Ctrl+s e makes scrollback a first-class text artifact you edit in nvim. tmux's copy-mode is a shadow of this.
